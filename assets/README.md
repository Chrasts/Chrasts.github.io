# Published website assets

This directory contains only assets intentionally published with the portfolio.

Use the structured media directories for new material:

- `documents/` — PDFs and other final document artifacts;
- `images/` — optimized raster/web images and screenshots;
- `diagrams/` — SVG/PNG/PDF diagrams intended as semantic scene objects;
- `audio/` — web-ready audio, not source/master recordings;
- `video/` — short web-ready demo clips only; prefer external hosting for larger video;
- `data/` — small sanitized datasets specifically required by portfolio visualizations.

The existing `stepan-chrast.jpg` stays at the root for backwards compatibility with current metadata and markup.

Files should be grouped first by media class, then by profile context (`work`, `education`, `about`, `certificates`, etc.) and finally by project/topic when useful.

Temporary ingestion notes or link dumps are not website assets; keep them outside this directory (for example in `content-inbox/`) until they are classified.

Do not use this repository as the master archive for private, raw, or large source files. See `PHASE7_5_ARTIFACT_FOUNDATION.md` and `artifact-data.js`.
